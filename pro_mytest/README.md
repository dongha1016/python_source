# 💕 발렌타인 럭키드로우

Flask로 만든 발렌타인데이 테마의 공 뽑기 당첨 웹앱입니다.

## 설치 및 실행

```bash
pip install flask
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속

## 구조

```
valentine_draw/
├── app.py              # Flask 서버 (API 포함)
└── templates/
    └── index.html      # 프론트엔드 (HTML/CSS/JS)
```

## 주요 기능

- **랜덤 공 뽑기** - 1~10번 공 중 랜덤 선택
- **선물 등급** - S / A / B / C 등급 시스템
- **애니메이션** - 공 스피닝 → 결과 팝업 → 반짝이 효과
- **배경** - 떠다니는 하트 애니메이션

## API

| 엔드포인트 | 설명 |
|-----------|------|
| `GET /` | 메인 페이지 |
| `GET /draw` | 랜덤 공 뽑기 결과 JSON 반환 |

### /draw 응답 예시

```json
{
  "ball": 4,
  "gift": "💌 손편지 + 커플링",
  "grade": "S",
  "color": "#FF1493"
}
```
